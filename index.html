完成 Firebase 設定

Google 登入需要連結你自己的 Firebase 專案，避免使用未經授權的登入設定。

  1. 在 Firebase Console 建立或選擇專案，新增 Web App。
  2. Authentication → Sign-in method 啟用 Google。
  3. Authorized domains 加入 a0908882056-bot.github.io。
  4. 將 Web App 的 Firebase config 填入本檔的 FIREBASE_CONFIG。
